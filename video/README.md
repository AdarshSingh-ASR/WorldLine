# WORLDLINE demo video

Programmatic hackathon edit built from the real 2:34 product recording.

- Remotion assembles footage, synchronized overlays, narration, and sound.
- HyperFrames renders the validated animated architecture segment.
- Kokoro TTS (`af_heart`) generates every narration clip locally.
- Source media and rendered outputs are intentionally gitignored.

Run `npm install`, `npm run voice`, render the HyperFrames composition, then `npm run render`.
